# TrọSmart MVP — Phase 8

## Added
- User verification API and JSON storage (`backend/data/verifications.json`).
- Verification panel in account profile.
- Verified-user badge beside landlord names on listing cards and room/map views.
- 20 additional demo rooms focused on Hai Bà Trưng / Bách Khoa and assigned to existing landlord accounts.
- Rich vertical map sidebar cards with images, prices, tags, landlord information and scroll layout.

## Constraint
- Existing files under `Docs/` were not modified.
- Verification is intentionally MVP-level: no OTP, OCR or third-party identity verification.
